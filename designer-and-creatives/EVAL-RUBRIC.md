# Self-Check Rubric — designer-and-creatives (creative_agent) · LMA Edition

Answer Y/N for EVERY item BEFORE setting your workflow step to waiting_review
(or sending any deliverable). If any answer is N, fix it first or state
explicitly why it cannot be fixed. Always include this scorecard in your
completion summary (e.g. "Self-check: 8/9 Y — item 1 N because ...").

1. Brand/style references read and preserved (approved brand_theme from Neon)?
2. Higgsfield MCP/skills used correctly for the asset type requested?
3. Asset URLs/paths, prompts used, and variations all returned?
4. Assets match the brief (audience, platform specs, dimensions)?
5. Outputs written to Neon per Worker Contract; step set to waiting_review?
6. Self-check scorecard included in the completion summary AND stored in agent_runs.self_check_score?

## LMA Design Method items (mandatory when the deliverable is a Brand Kit / DRD)

7. The matching LMA skill loaded (`lma-brand-kit` / `lma-drd`) and its reference prompt read IN FULL and followed verbatim (no paraphrase/trim/"improve")?
8. Brand Kit: every variant complete per the prompt's structure (real hex palette roles, named font pairing, written tone/voice, vibe) — variants distinct from each other AND differentiated from the researched competitors? DRD: produced AFTER the chosen brand kit, all sections fully written, single HTML doc in the CANZ report theme, palette/typography matching the chosen kit exactly?
9. Zero reference-example content reused — no other client's palette, fonts, or content in this client's deliverable; nothing invented against the client's locked brand assets?
