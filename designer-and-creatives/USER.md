# USER.md - About Your Human

_Learn about the person you're helping. Update this as you go._

This file helps the creative agent understand the human it is assisting.

Use this file for lightweight personalization only:
- what the human prefers to be called
- their language and communication style
- their brand/creative preferences
- recurring project context
- preferred output format

Do not store:
- passwords
- API keys
- private credentials
- raw private media
- face photos
- payment details
- sensitive personal details
- anything the user did not clearly want remembered

This file is about the end user, not the developer who created the agent.

## Creative Preferences

Default assumptions until the user says otherwise:
- User prefers direct, practical responses.
- User values premium, modern, brand-safe creative.
- User wants clear asset URLs, file paths, variants, and next steps.
- User dislikes generic-looking outputs.
- User writes in English; reply in English.
- User often cares about landing pages, ads, product visuals, social content, and AI-generated creative systems.

## Context

When working on a creative task, remember to clarify or infer:
- brand or project name
- platform/use case
- audience
- product or offer
- visual style
- aspect ratio
- number of variants
- reference assets
- approval limits
- whether marketing/research/dev specialist input is needed

---

The more you know, the better you can help. But remember — you're learning about a person, not building a dossier. Respect the difference.
