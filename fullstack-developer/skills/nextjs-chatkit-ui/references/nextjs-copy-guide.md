## Subtitle Writing Rules

```
DO:
- Keep to 1-2 sentences maximum
- Include a specific benefit or number
- Address the reader directly ("you", "your")
- Complement the headline (add detail, don't repeat)

DON'T:
- Repeat the headline in different words
- Use vague language ("best in class", "world-class")
- Write more than 160 characters
- Use jargon the target audience won't know
```

### Examples

```
WEAK: "We provide the best service for all your needs."
STRONG: "Join 2,500+ businesses saving 15 hours/week with AI-powered automation."

WEAK: "Welcome to our website."
STRONG: "From raw data to actionable insights in under 5 minutes."
```

## CTA Button Text

### Primary CTAs (High commitment)

| Niche | Strong CTAs |
|-------|------------|
| Restaurant | "Reserve Your Table", "Order Now", "View Our Menu" |
| SaaS | "Start Free Trial", "Get Started Free", "See It In Action" |
| Clinic | "Book Appointment", "Schedule a Visit", "Find Your Doctor" |
| E-commerce | "Shop Now", "Browse Collection", "Get 20% Off" |
| Portfolio | "View My Work", "Let's Talk", "Start a Project" |
| Agency | "Get a Free Quote", "Book a Strategy Call", "See Our Work" |
| Education | "Enroll Now", "Start Learning Free", "Browse Courses" |

### Secondary CTAs (Low commitment)

```
"Watch Demo" / "See How It Works"
"Learn More" / "Explore Features"
"View Pricing" / "Compare Plans"
"Talk to Sales" / "Contact Us"
```

### CTA Rules

```
NEVER use:
- "Submit"
- "Click Here"
- "Read More" (as primary CTA)
- "Enter" / "Go"

ALWAYS:
- Start with a verb
- Be specific about what happens next
- Match the user's intent level
- Primary: high contrast, large
- Secondary: outline/ghost, same size
```

## Feature Description Writing

### Structure Per Feature

```
Title: 3-5 words, benefit-focused
Description: 1-2 sentences explaining HOW it helps the user

Example:
Title: "Real-Time Analytics"
Description: "Monitor your key metrics as they happen. Get instant alerts when something needs your attention."

NOT:
Title: "Analytics Feature"
Description: "We have analytics that show data in real-time with various visualization options."
```

### Feature Copy Rules

```
1. Lead with the BENEFIT, not the feature
   ❌ "We use machine learning algorithms"
   ✅ "Predict trends before they happen"

2. Use "you/your" not "we/our"
   ❌ "Our platform provides..."
   ✅ "Get instant access to..."

3. Be specific, not vague
   ❌ "Fast performance"
   ✅ "Sub-200ms response times"

4. One benefit per feature card
   Don't list multiple benefits — pick the strongest one
```

## Testimonial Writing Guidelines

When generating placeholder testimonials (for templates):

```
Structure:
"[Specific result/outcome]. [How it changed their workflow]. [Recommendation]."

Example:
"We reduced our data analysis time from 3 hours to 15 minutes.
The AI predictions helped us catch a market shift 3 weeks before our competitors.
If you're serious about data-driven growth, this is the tool."

Rules:
- Include specific numbers/timeframes
- Mention the author's role and company
- Keep to 2-3 sentences
- Sound natural, not marketing-speak
- Include 5-star rating
```

## FAQ Content Strategy

### What to Include

```
1. Objection handlers — address reasons people DON'T buy
   "Is my data secure?" → Yes, SOC 2 certified + AES-256
   "Can I cancel anytime?" → Yes, no contracts

2. Clarifying questions — remove confusion
   "How long does setup take?" → Under 5 minutes
   "Do I need technical knowledge?" → No, guided wizard

3. Differentiators — why you vs competitors
   "How is this different from [competitor]?" → specific advantages

4. Process questions — what happens next
   "What happens after I sign up?" → walkthrough of onboarding
```

### FAQ Format

```
Question: Direct, specific (how the user would actually ask)
Answer: 2-4 sentences. Lead with the direct answer, then elaborate.

✅ Q: "How long does setup take?"
   A: "Most teams are up and running in under 5 minutes. Our guided wizard walks you through
      connecting your data sources. No technical knowledge required."

❌ Q: "What is the setup process like?"
   A: "Our company has developed a comprehensive onboarding system that leverages cutting-edge
      technology to facilitate a seamless integration experience..." (too corporate)
```

## Microcopy

### Form Labels

```
✅ "Your Name" / "Full Name"
✅ "Work Email" / "Email Address"
✅ "Phone Number (optional)"
✅ "Tell us about your project"

❌ "Name:" (no colon, no placeholder-only)
❌ "Enter your electronic mail address"
```

### Form Validation Messages

```
Empty field: "Please enter your [field name]"
Invalid email: "Please enter a valid email address"
Too short: "Must be at least [X] characters"
Success: "Thanks! We'll be in touch within 24 hours."
```

### Empty States

```
No results: "No [items] found. Try adjusting your filters."
No reviews: "Be the first to leave a review!"
Loading: Show skeleton, not "Loading..."
Error: "Something went wrong. Please try again."
```

### Button Loading States

```
Default: "Send Message"
Loading: "Sending..." (with spinner)
Success: "Sent!" (with checkmark, auto-revert after 2s)
Error: "Failed — Try Again"
```
