## Rules
1. LP task → `lma-lp-structure`; multi-page site → `lma-website-structure`; both load `lma-visual-implementation` at Phase 5.
2. Study at least 2 reference examples (closest niche + one other) BEFORE blueprinting.
3. Examples give SHAPE — the client's approved research gives WORDS. Never reuse example copy/claims.
4. The 9-phase premium workflow, hero 12/12 gate, QA gates, and Canz static HTML/CSS/JS standard stay exactly as the handbook says.
