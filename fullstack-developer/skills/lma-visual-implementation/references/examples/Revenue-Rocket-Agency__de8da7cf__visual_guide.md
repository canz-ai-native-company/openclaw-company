# Visual Guide 1 — Futuristic Minimalism  
**Rating:** 9.7/10  

## Typography  
- Headings: GT Walsheim Pro, Weight 700 (Bold) — modern geometric sans-serif with confident, clean lines.  
- Paragraphs: Open Sans, Weight 400 (Regular) — highly legible humanist sans-serif for approachable reading.  

## Colors  
- Primary: #5F4B8B (Royal Purple) — conveys luxury and advanced technology.  
- Secondary: #C7D3F2 (Soft Periwinkle) — feminine, calming accent.  
- Background: #F9FAFB (Almost White Gray) — minimal and clean.  
- Surface: #FFFFFF (Pure White) — content card backgrounds and surfaces.  
- Text Primary: #222222 (Rich Charcoal) — high contrast, easy reading.  
- Text Secondary: #6C6C6C (Medium Gray) — for subtitles and less prominent text.  
- Border: #E2E6EA (Light Cool Gray) — subtle and clean lines.  
- Success: #3BE07A (Vivid Green) — progress and positive feedback.  
- Error: #E03E3E (Bright Red) — clear error indication.  

## Layout  
- Grid: 12-column, mobile-first, responsive with columns stacking vertically on mobile under 768px.  
- Gutter: 20px on mobile, scaling up to 24px desktop.  
- Max container width: ~1200px desktop to maintain premium balance and white space.  
- Section spacing: ~80px vertical padding between major sections.  

## Buttons  
- Primary: background #5F4B8B, text #FFFFFF  
- Hover: background #4A3B6A  
- Active: background #3A2D53  
- Disabled: background #B5ABC6, text #7E7A8D  
- Focus: 3px solid #C7D3F2 with 4px offset shadow for distinct keyboard focus.  
- Keyboard Navigation: Tab to cycle through interactive elements with visible focus ring; Enter/Space triggers button action.  

## Motion  
- Default: smooth 250ms ease-in-out transitions for color and background changes on hover and focus states.  
- Reduce Motion: prefers-reduced-motion media query disables all non-essential animations and disables transition duration to instantaneous.  

## Accessibility  
- Contrast ratio: All text and button colors meet WCAG 2.1 AA standards minimum (4.5:1 for normal text, 3:1 for large text).  
- Focus indicators: Clearly visible 3px purple outline with offset shadow for keyboard users, ensuring strong visible feedback.  
- Keyboard Navigation: All interactive elements are reachable and operable using keyboard alone (Tab, Shift+Tab, Enter, and Space keys).  
- Reduced-motion: Animations respect user OS preferences, disabling motion where requested.  

## Asset Checklist  
- Logo in SVG + PNG (light and dark versions)  
- Favicon set (including standard, retina, and Apple touch icons)  
- Button state graphical assets (icons or backgrounds if used)  
- Icon set: minimal line icons optimized as SVG for UI states  
- Illustration set: futuristic, geometric shapes with feminine color overlays in SVG + PNG formats  
- Webfont files for GT Walsheim Pro and Open Sans (WOFF2 preferred)  
- Responsive images in 1x and 2x resolutions, optimized for fast loading

# Visual Guide 2 — Modern Luxury Tech  
**Rating:** 9.8/10  

## Typography  
- Headings: Montserrat, Weight 600 (Semi-Bold) — sharp, modern sans serif that feels premium and confident.  
- Paragraphs: Lato, Weight 400 (Regular) — clean and friendly sans serif for clarity and comfort.  

## Colors  
- Primary: #3B2F63 (Deep Indigo) — strong, sophisticated, tech-forward hue.  
- Secondary: #E1BFDD (Lavender Blush) — soft and feminine accent tone.  
- Background: #FAFAFA (Ultra Light Gray) — bright and airy for luxury feel.  
- Surface: #FFFFFF (Pure White) — cards, modals, and UI surfaces background.  
- Text Primary: #1F1F1F (Very Dark Gray) — sharp contrast for reading comfort.  
- Text Secondary: #7A7A7A (Warm Gray) — secondary or supporting text.  
- Border: #DDDCE1 (Light Neutral Gray) — subtle line elements and dividers.  
- Success: #26D07A (Bright Mint Green) — positive feedback and success states.  
- Error: #D0342C (Strong Red) — clear error or danger states indicator.  

## Layout  
- Grid: 12-column flexible grid, mobile-first with columns stacking vertically for screens <768px.  
- Gutter: 24px desktop, 16px mobile for balanced white space.  
- Max container width: ~1200px desktop for clean, elegant composition.  
- Section spacing: consistent ~80px vertical spacing for roomy layout.  

## Buttons  
- Primary: background #3B2F63, text #F9FAFB  
- Hover: background #342A56  
- Active: background #2B2245  
- Disabled: background #BDB9C7, text #8C869C  
- Focus: 3px solid #E1BFDD with subtle glow shadow for keyboard focus visibility.  
- Keyboard Navigation: Logical tab order, focus ring is visible and distinct, keyboard triggers (Enter/Space) activate buttons.  

## Motion  
- Default: 300ms cubic-bezier(.4,0,.2,1) transition for background-color, color, box-shadow for smooth and natural feedback.  
- Reduce Motion: disables transitions, no opacity or transform animations per user preference.  

## Accessibility  
- Contrast ratio: All text and button states exceed WCAG AA standards (4.5:1 for body text; 3:1 for large text).  
- Focus indicators: High contrast visible ring with subtle glow around buttons and interactive fields; large enough for visibility.  
- Keyboard navigation: All functionality accessible via keyboard without traps or loss of focus.  
- Reduced-motion: Utilizes prefers-reduced-motion to disable non-essential animations and maintain comfort for sensitive users.  

## Asset Checklist  
- Logo SVG and PNG, including monochrome and full-color versions  
- Favicons optimized for multiple devices and platforms  
- Interactive button state assets (SVG icons and backgrounds if applicable)  
- Iconography set crafted in vector SVG for UI consistency  
- Custom illustrations emphasizing feminine tech elements in accessible color palette, delivered in SVG & PNG  
- Webfont packages for Montserrat and Lato (WOFF2 formats)  
- Optimized responsive images in standard and high-density ratios (1x, 2x)
