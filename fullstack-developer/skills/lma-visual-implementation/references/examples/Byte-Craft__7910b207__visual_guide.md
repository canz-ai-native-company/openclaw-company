# Visual Guide 1 — Futuristic Tech Minimalism  
**Rating:** 9.7/10  

## Typography  
- Headings: "Montserrat", Semi-Bold (600) — geometric, modern, tech-forward  
- Paragraphs: "Roboto", Regular (400) — clean, highly readable, neutral  

## Colors  
- Primary: #3AB0FF (electric blue)  
- Secondary: #6E7B8B (cool slate gray)  
- Background: #121621 (near-black navy)  
- Surface: #1E2638 (dark steel slate)  
- Text Primary: #E1E6F0 (soft white)  
- Text Secondary: #A0A8B8 (muted gray-blue)  
- Border: #2F3B56 (desaturated blue-gray)  
- Success: #14C38E (vivid turquoise)  
- Error: #FF4A5F (bright coral red)  

## Layout  
- Grid: 12-column, mobile-first with explicit breakpoints at 480px, 768px, 1024px  
- Gutter: 24px horizontal spacing  
- Max container width: ~1200px on desktop  
- Section vertical spacing: ~80px consistent padding/margin above and below  

## Buttons  
- Primary: background #3AB0FF, text #121621  
- Hover: background #2A8FE6 (darker electric blue)  
- Active: background #1E6FCC (deeper blue)  
- Disabled: background #587EA8, text #A0A8B8  
- Focus: 3px solid #14C38E outline with 6px focus ring offset  
- Keyboard navigation: Tab to focus buttons, use Enter/Space to activate; visible focus ring with distinct color  

## Motion  
- Default: transitions 250ms ease-in-out on background-color and box-shadow  
- Reduced Motion: motion reduced users see instant state changes, no animations, no focus ring transitions  

## Accessibility  
- Contrast ratio: All text passes WCAG AA minimum 4.5:1 or better; primary text on background 15:1  
- Focus indicators: Highly visible, thick color outlines with offset  
- Keyboard navigation: Logical, linear tab order; all interactive elements are reachable  
- Reduced-motion: Users with prefers-reduced-motion enabled see no animations or transitions  

## Asset Checklist  
- Logo: SVG format with metallic gradient + PNG in 2 sizes (512px, 128px)  
- Favicon set: ICO + PNG variants (16px, 32px, 48px)  
- Button state assets: none (CSS-based states)  
- Icons: SVG optimized icons set (including HVAC-specific tools, tech gadgets)  
- Illustration set: futuristic HVAC tech line-art style in SVG and PNG  
- Font files: Montserrat & Roboto WOFF2 + fallback fonts  
- Responsive images: JPG/WEBP for hero, content images @1x (768px wide), @2x (1536px wide)

# Visual Guide 2 — Sleek Metallic Innovation  
**Rating:** 9.8/10  

## Typography  
- Headings: "Orbitron", Bold (700) — futuristic, mechanical style  
- Paragraphs: "Open Sans", Regular (400) — clean, neutral, accessible  

## Colors  
- Primary: #00A3FF (bright cyan)  
- Secondary: #5D6D7E (silvery graphite)  
- Background: #0D1117 (midnight black)  
- Surface: #222B38 (dark metallic blue)  
- Text Primary: #E6EDF3 (soft pale gray)  
- Text Secondary: #8A9BA8 (cool muted silver)  
- Border: #33475B (steel gray)  
- Success: #27CCA1 (fresh teal)  
- Error: #FF3864 (dynamic red)  

## Layout  
- Grid: 12-column, mobile-first, breakpoints at 480px, 768px, 1024px  
- Gutter: 20px horizontal space  
- Max container width: ~1200px on large screens  
- Section spacing: consistent ~80px vertical margin/padding  

## Buttons  
- Primary: background #00A3FF, text #0D1117  
- Hover: background #007FCC (deeper cyan)  
- Active: background #005D99 (dark cyan)  
- Disabled: background #768694, text #BAC5D0  
- Focus: 2px solid #27CCA1 focus outline with 5px offset ring  
- Keyboard navigation: Full tab focus on all buttons and controls, visual ring on focus, activation with Enter or Space keys  

## Motion  
- Default: smooth 200ms cubic-bezier(0.4, 0, 0.2, 1) transitions on background and shadow  
- Reduced Motion: no animations or transitions, instant state changes for disabled and hover  

## Accessibility  
- Contrast ratio: All text meets or exceeds WCAG AAA minimum contrast (7:1)  
- Focus indicators: Strong visible outlines distinct from color backgrounds using teal ring  
- Keyboard navigation: Clear tab sequence, interactive elements are keyboard accessible with visible focus  
- Reduced-motion support: Prefers-reduced-motion media query disables all non-essential motion  

## Asset Checklist  
- Logo: Metallic chrome effect SVG + high-res PNG (1024px, 256px)  
- Favicon: Full set ICO + PNG (16, 32, 48 px) with sharp, crisp icon  
- Button states: Pure CSS states for toggles & buttons, no image assets needed  
- Icons: Set of 20 custom SVG icons with metallic gradients relevant to HVAC & tech  
- Illustration set: Stylized dynamic HVAC system diagrams in SVG with metallic accents  
- Fonts: Orbitron & Open Sans WOFF2 plus system fallbacks  
- Responsive images: Optimized JPG and WebP hero images at 1x (800px) and 2x (1600px) resolution
