# Lovable.dev Website Design Prompt (for Front-End/Designers)

---
**Fonts:**  
- Headings: Poppins Bold/700  
- Body: Inter Regular/500

**Color Palette:**  
- Deep Blue #1b4f72 (dominant, background/CTA/buttons)  
- Blue-Gray #6b7280 (support, icons)  
- Midnight Ink #1f2933/#111827 (headings/text)  
- Highlight #f3f4ff (panels/benefit chip backgrounds)  
- Teal/Green accent (micro details, glow, checked states)

**Page Flow:**  
- Home > Services > Case Studies > Contact  
- Each page alternates parallax image and plain content; never the same layout twice  
- Home and Case Studies pages begin and end with high-impact, metric-forward hero/CTA parallax visuals  
- Footer persistent, centered, minimal with compliance badges

**Parallax/Animation Rules:**  
- All parallax images must be layered: foreground (people, contracts), mid (floating folders/badges/glass cards), background (network grids, compliance icons)  
- Section fade-ups, slide-ins, card reveals (staggered) everywhere  
- Animated counters on all metrics/stats  
- Benefit and case cards lift and glow on hover, with subtle glassmorphism  
- CTA buttons shimmer, glow on hover, and micro-scale up  
- Text entry animations (letter reveal, shimmer highlight, slide-in), not static

**Image Style:**  
- Premium, cinematic, workplace/team-driven (no clichés: avoid neon, hacker-hoodies, or code walls)  
- Real people, executive digital environments, abstract line/network overlays  
- Vivid blue/white, occasional teal/green highlights  
- Each parallax image: specify depth (foreground execs/contracts, mid badges, back grid/lines)

**Card Style:**  
- Glass feel with blue accent shadows  
- Animated icons (line-based, minimal fills)  
- Soft lifts and glows on hover  
- Staggered entrance animations

**CTA Styling:**  
- Solid #1b4f72, white text, glowing border/shadow, micro-scale on hover  
- Always contrasts section: use highlight panels or dark-over-image as necessary

**Footer Design:**  
- Centered logo  
- Compliance badges (SOC2, HIPAA, CMMC, FTC), muted but clear  
- Policies/links, slim copyright  
- Soft fade-in footer entrance

**Unique Decorative Guidance:**  
- Never repeat grid/card layouts from one page to the next  
- Combine floating data stats/chips and network overlays for cyber vibe  
- Each page has a unique spatial/visual identity: image placement, grid types, CTA position, and parallax effect are never duplicated  
- Decorative overlays: lines, dotted grids, light badges, but always subtle, never crowded

**Everything must radiate credibility, speed, and proven B2B outcomes in cybersecurity.**
