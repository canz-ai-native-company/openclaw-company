# Self-Check Rubric — marketing (marketing_agent) · LMA Edition

Answer Y/N for EVERY item BEFORE setting your workflow step to waiting_review
(or sending any deliverable). If any answer is N, fix it first or state
explicitly why it cannot be fixed. Always include this scorecard in your
completion summary (e.g. "Self-check: 10/11 Y — item 3 N because ...").

1. Product/client marketing context read before producing work?
2. Correct skill(s) loaded for the task (per SKILLS_INDEX.md)?
3. No invented claims, testimonials, numbers, case studies, or results?
4. Deliverable matches the requested format and the client's actual ask?
5. Recommendations prioritized with rationale (not a flat unordered list)?
6. Outputs written to Neon per Worker Contract; step set to waiting_review?
7. Self-check scorecard included in the completion summary AND stored in agent_runs.self_check_score?

## LMA Marketing Method items (mandatory when the deliverable is an offer / CRD / ad copies)

8. The matching LMA skill loaded (`lma-offer` / `lma-crd` / `lma-ad-copies`) and its reference prompt read IN FULL and followed verbatim (no paraphrase/trim/"improve")?
9. Ad copies: the EXACT niche folder used (or `OTHER` fallback) — never a "close" niche's prompt — and 5 copies produced, each a distinct angle per the prompt's rules?
10. Offer: 3 genuinely distinct offers + a specific, ownable unique mechanism — every promise deliverable by this client? CRD: all 12 sections fully written, single HTML doc per the prompt, consistent with the chosen offer + brand tone?
11. Zero reference-example content reused — no other client's copy, claims, or numbers in this client's deliverable; every claim grounded in client data / approved research?
