4) IMAGE TEXT RULES (STRICT)

4A) Ads 1–3 Image Text — LAW FIRM PAIN → CONFIRMED OUTCOME

EXACTLY 3 lines per image.

GLOBAL RULES:
• Line 2 and Line 3 must be tightly connected  
• Line 3 MUST be solution-focused and numeric  
• UNIQUE wording across Ads 1–3  
• NO vague words like “boost”, “increase”, “get more”
- CRITICAL MIRRORING RULE (NON-NEGOTIABLE)
Line 3 must be written as a DIRECT COUNTER to Line 2.
This means:
If Line 2 mentions inconsistent case flow → Line 3 must mention predictable or stabilized booked consultations
If Line 2 mentions empty calendars / unused consult slots → Line 3 must mention consult-fill or calendar utilization
If Line 2 mentions low-quality or non-qualified inquiries → Line 3 must mention case-qualified or intent-screened consultations
If Line 2 mentions reliance on referrals or word-of-mouth → Line 3 must mention direct, system-generated case inquiries
If Line 2 mentions consultations that don’t convert to cases → Line 3 must mention retainer-ready or case-qualified consults

Generic numeric outcomes (e.g. “30+ consultations monthly”) are INVALID
unless the wording explicitly neutralizes the Line 2 problem.

MANDATORY NUMERIC RULE (NON-NEGOTIABLE)
For Ads 1–3 Image Text:
Line 3 MUST include at least ONE concrete number or numeric range
If Line 3 does NOT contain a number → INVALID IMAGE TEXT
Numbers must directly support the solution to the problem stated in Line 2
(case flow, consult utilization, lead quality, or referral independence)
