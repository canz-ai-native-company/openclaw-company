4) IMAGE TEXT RULES (STRICT)

4A) Ads 1–3 Image Text — HOSPITALITY PAIN → CONFIRMED OUTCOME

EXACTLY 3 lines per image.

GLOBAL RULES:
• Line 2 and Line 3 must be tightly connected  
• Line 3 MUST be solution-focused and numeric  
• UNIQUE wording across Ads 1–3  
• NO vague words like “boost”, “increase”, “get more”
-CRITICAL MIRRORING RULE (NON-NEGOTIABLE)
Line 3 must be written as a DIRECT COUNTER to Line 2.

This means:
If Line 2 mentions inconsistent covers or foot traffic → Line 3 must mention predictable or stabilized daily/weekly covers
If Line 2 mentions empty tables or low off-peak utilization → Line 3 must mention table-fill or seat utilization
If Line 2 mentions low-intent bookings or no-shows → Line 3 must mention confirmed, pre-qualified reservations
If Line 2 mentions reliance on walk-ins or platforms → Line 3 must mention direct, owned reservations
If Line 2 mentions slow weekdays or off-peak hours → Line 3 must mention off-peak demand generation
Generic numeric outcomes (e.g. “200+ covers monthly”) are INVALID
unless the wording explicitly neutralizes the Line 2 problem.

MANDATORY NUMERIC RULE (NON-NEGOTIABLE)
For Ads 1–3 Image Text:
Line 3 MUST include at least ONE concrete number or numeric range
If Line 3 does NOT contain a number → INVALID IMAGE TEXT
Numbers must directly support the solution to the problem stated in Line 2
(covers, reservations, utilization, or demand consistency)

IMAGE TEXT FORMAT (Ads 1–3)
Line 1: [Restaurant / Hospitality niche callout]
Line 2: [Specific demand, booking, or utilization problem]
