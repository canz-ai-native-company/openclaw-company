4) IMAGE TEXT RULES (STRICT)

4A) Ads 1–3 Image Text — AGENT PAIN → CONFIRMED OUTCOME

EXACTLY 3 lines per image.

GLOBAL RULES:
• Line 2 and Line 3 must be tightly connected  
• Line 3 MUST be solution-focused and numeric  
• UNIQUE wording across Ads 1–3  
• NO vague words like “boost”, “increase”, “get more”
- CRITICAL MIRRORING RULE (NON-NEGOTIABLE)
Line 3 must be written as a DIRECT COUNTER to Line 2.

This means:
If Line 2 mentions inconsistent buyer/seller lead flow → Line 3 must mention predictable or stabilized booked appointments
If Line 2 mentions empty calendars or slow weeks → Line 3 must mention calendar-fill or appointment utilization
If Line 2 mentions low-quality or unmotivated leads → Line 3 must mention pre-qualified buyer/seller appointments
If Line 2 mentions reliance on referrals or platforms → Line 3 must mention direct, system-generated appointments
If Line 2 mentions showings or calls that don’t convert to listings → Line 3 must mention listing-ready or transaction-ready appointments

Generic numeric outcomes (e.g. “30+ appointments monthly”) are INVALID
unless the wording explicitly neutralizes the Line 2 problem.

MANDATORY NUMERIC RULE (NON-NEGOTIABLE)

For Ads 1–3 Image Text:
Line 3 MUST include at least ONE concrete number or numeric range
If Line 3 does NOT contain a number → INVALID IMAGE TEXT

Numbers must directly support the solution to the problem stated in Line 2
(appointment volume, calendar utilization, lead quality, or referral independence)

IMAGE TEXT FORMAT (Ads 1–3)

Line 1: [Real estate niche callout]
Line 2: [Specific buyer/seller acquisition or calendar problem]
Line 3: Get / We give you [Direct solution to that problem, with numbers]

CANONICAL EXAMPLES (REAL ESTATE)
Example 1 — Inconsistent Deal Flow
Line 1: Real Estate Agents
Line 2: Still dealing with inconsistent buyer and seller leads?
Line 3: We stabilize demand with 20–35 booked buyer/seller appointments monthly

Example 2 — Empty Calendars
Line 1: Realtors
Line 2: Too many slow weeks with no appointments?
Line 3: We fill your calendar with 15–30 pre-qualified appointments per month

Example 3 — Referral / Platform Dependency
Line 1: Real Estate Brokerages
Line 2: Still relying on referrals or listing platforms for clients?
Line 3: We generate 25+ direct buyer & seller appointments monthly

Example 4 — Appointments Not Converting
Line 1: Residential Agents
Line 2: Taking showings that never turn into listings?
Line 3: We deliver 8–15 listing-ready appointments monthly

FINAL VALIDATION CHECK (STRICT)
If Line 3 could apply to a different problem → INVALID
If Line 3 could be written without a number → INVALID
All Image Text across Ads 1–3 must be unique in wording and numbers
