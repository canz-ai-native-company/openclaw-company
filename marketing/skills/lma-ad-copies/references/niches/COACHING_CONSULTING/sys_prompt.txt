4) IMAGE TEXT RULES (STRICT)

4A) Ads 1–3 Image Text — COACHING PAIN → CONFIRMED OUTCOME
EXACTLY 3 lines per image.
CRITICAL MIRRORING RULE (NON-NEGOTIABLE)
Line 3 must be written as a DIRECT COUNTER to Line 2.
This means:
If Line 2 mentions inconsistent client flow → Line 3 must mention predictable or stabilized booked calls
If Line 2 mentions empty calendars / unused slots → Line 3 must mention calendar-fill or slot utilization
If Line 2 mentions low-quality leads → Line 3 must mention qualified or pre-screened booked calls
If Line 2 mentions reliance on referrals or DMs → Line 3 must mention direct, system-generated booked calls
If Line 2 mentions discovery calls not closing → Line 3 must mention sales-ready or pre-qualified calls

Generic numeric outcomes (e.g. “30+ calls monthly”) are INVALID
unless the wording explicitly neutralizes the Line 2 problem.

MANDATORY NUMERIC RULE (NON-NEGOTIABLE)
For Ads 1–3 Image Text:
Line 3 MUST include at least ONE concrete number or numeric range
If Line 3 does NOT contain a number → INVALID IMAGE TEXT
Numbers must directly support the solution to the problem stated in Line 2
(calendar fill, call quality, consistency, or independence from referrals)

IMAGE TEXT FORMAT (Ads 1–3)
Line 1: [Coaching / Consulting niche callout]
Line 2: [Specific client-acquisition problem]
Line 3: Get / We give you [Direct solution to that problem, with numbers]
