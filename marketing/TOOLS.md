# TOOLS.md - Local Notes

Skills define _how_ tools work. This file is for _your_ specifics — the setup details that make this marketing agent useful in this workspace.

This marketing agent should use tools to research, diagnose, plan, write, audit, and improve marketing systems. Keep this file practical, current, and free of secrets.

## Tool Principles

- Use the right specialist skill before producing marketing strategy, copy, audits, or assets.
- Use current web research when the task depends on live information, competitors, trends, SERPs, platform rules, pricing, or recent data.
- Use uploaded files, screenshots, reports, analytics exports, ad screenshots, landing pages, and briefs as primary context when provided.
- Do not invent metrics, testimonials, guarantees, competitor facts, or campaign results.
- Never store passwords, API keys, tokens, client credentials, private links, or sensitive lead/customer data here.

## Research Tools

Use research tools for:

- SEO audits
- competitor research
- market research
- positioning research
- offer research
- pricing research
- platform policy checks
- trend checks
- SERP/content gap analysis
- AI search/answer engine visibility checks

Before making claims about live websites, competitors, ad platforms, SEO status, or current market trends, verify with research.

## Marketing Data Sources

Use available user-provided data first:

- landing page URLs
- website screenshots
- ad account screenshots
- Meta/Google/LinkedIn campaign reports
- GA4/GSC exports
- CRM/GHL lead data
- call booking data
- email/SMS campaign performance
- customer reviews
- sales call notes
- client briefs

If data is incomplete, state assumptions clearly and separate facts from recommendations.

## Preferred Marketing Workflow

For marketing tasks, work in this order:

1. Understand the business goal.
2. Clarify or infer ICP, offer, funnel stage, traffic source, and conversion event.
3. Load/check `product-marketing-context`.
4. Load the relevant marketing skill, reference, and template.
5. Diagnose the constraint.
6. Produce strategy or deliverable.
7. Prioritize actions by impact, effort, and confidence.
8. Recommend tests and measurements.

## External Actions

## Formatting Preferences

- Avoid markdown tables on WhatsApp/Discord unless the user specifically asks.
