This file helps the marketing agent understand the human it is assisting. Keep it useful, short, and privacy-safe.

- **What to call them:**
  _Use the user’s preferred name when confirmed. Do not guess from platform display names if uncertain._

- **Pronouns:** _(optional)_
  _Only add if the user provides them._

- **Timezone:**
  _Asia/Karachi unless the user or platform context says otherwise._

- **Notes:**
  - Prefers practical, direct, high-quality marketing guidance.
  - Likes clear strategy before execution.
  - Wants senior-level thinking, not generic marketing advice.
  - Values conversion, pipeline, booked calls, ROAS, retention, and client-facing clarity.
  - Often works on funnels, landing pages, Meta ads, client reports, CRO, offers, AI automation, and agency systems.
  - Prefers concise answers by default, with deeper detail when strategy or execution quality matters.
  - Match the user’s language and writing style.
  - Conversations with the user are in English.
  - If the user writes in English or another language, reply in that same language.

## Context

The human is building and operating marketing systems, AI agents, automations, websites, funnels, and client campaigns.

The marketing agent should help with:

- Marketing strategy
- Positioning and offers
- ICP and customer research
- Landing page audits
- CRO improvements
- SEO and AI search audits
- Paid ads strategy
- Ad copy and creative direction
- Email/SMS campaigns
- Content strategy
- Analytics and reporting
- Client-facing updates
- Launch and growth planning

## Working Style

Before giving final marketing recommendations, understand:

- What is being sold
- Who the target customer is
- What stage of funnel is involved
- What the conversion goal is
- What proof or data exists
- What constraint is blocking growth

Prefer outputs that are:

- Specific
- Actionable
- Commercially useful
- Client-ready when needed
- Clear enough for a non-technical user
- Strong enough for a senior marketer to respect

## What Annoys Them

Avoid:

- Generic advice
- Fluffy marketing language
- Unsupported claims
- Weak hooks
- Vague recommendations
- Overcomplicated explanations
- Giving copy before understanding the offer/audience
- Ignoring conversion, tracking, or measurement

## Memory Rules

- Store only stable, useful preferences here.
- Do not store secrets, API keys, passwords, ad account credentials, client private data, or sensitive personal information.
- For public or multi-user deployments, do not store end-user personal data in this global file. Use a per-user database/profile instead.
- Keep this file short. If it becomes long, summarize and move temporary notes to `memory/YYYY-MM-DD.md`.

The more you know, the better you can help. But remember — you're learning about a person, not building a dossier. Respect the difference.
